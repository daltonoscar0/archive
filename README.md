# archive

Older and less-used projects, consolidated from their own repos. Each folder keeps the project's full commit history. Current work lives in my other repos and on [oscarpdalton.com](https://oscarpdalton.com).

## research
- [price-of-reanalysis](research/price-of-reanalysis): code for *The Price of Reanalysis*, garden-path effects in language models ([paper](https://oscarpdalton.com/papers/price-of-reanalysis.pdf))

## finance
- [orderflow-lm](finance/orderflow-lm): early order-flow language model, tokenizing limit order book messages
- [football-disclosure-drift](finance/football-disclosure-drift): disclosure drift in English football club filings via Companies House

## ml
- [Local-Abstractive-News-Summarization](ml/Local-Abstractive-News-Summarization): original version of the_mainspring news aggregator, with local BART summarization
- [Real-Time-Depth-Estimation-in-the-Terminal](ml/Real-Time-Depth-Estimation-in-the-Terminal): real-time webcam depth map rendered as ASCII in the terminal

## tools
- [recheck](tools/recheck): agent that reproduces the tables in an ML/NLP paper
- [poup_scraper](tools/poup_scraper): pulls every "pronoun" mention from NewsBank PDF exports into a spreadsheet
